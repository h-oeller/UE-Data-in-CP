# Data Labs

This repository contains the files and data used in the four Data Labs of the course **„Ü Methoden der Vergleichenden Regierungslehre: Daten in der vergleichenden Politikwissenschaft: Konzepte, Messungen und Forschungsdesigns“**.

The Data Labs provide hands-on opportunities to explore political science datasets, understand how concepts are measured, and develop research ideas.

Materials include:

- Short handouts with exploration tasks.
- Quarto (`.qmd`) files with introductory R code.
- Data files or instructions for accessing the datasets.

Download the materials for the relevant session and open the `.qmd` file in RStudio to work through the examples. Follow the preparation instructions to install any required packages. Where available, you can also use the data projects’ online tools.

Please consult the original data providers’ documentation for definitions, coverage, citation requirements, and terms of use.
